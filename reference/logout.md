# Logout of the EDI repository

Logout of the EDI repository

## Usage

``` r
logout()
```

## Value

(NULL) No return value.

## Details

Removes the temporary authentication token system variable "EDI_TOKEN".

## See also

Other Authentication:
[`login()`](https://docs.ropensci.org/EDIutils/reference/login.md)

## Examples

``` r
if (FALSE) { # \dontrun{
logout()
} # }
```
