# Read data entity name

Read data entity name

## Usage

``` r
read_data_entity_name(packageId, entityId, env = "production")
```

## Arguments

- packageId:

  (character) Data package identifier

- entityId:

  (character) Data entity identifier

- env:

  (character) Repository environment. Can be: "production", "staging",
  or "development".

## Value

(character) Name of `entityId` in `packageId`
