# Read data entity checksum

Read data entity checksum

## Usage

``` r
read_data_entity_checksum(packageId, entityId, env = "production")
```

## Arguments

- packageId:

  (character) Data package identifier

- entityId:

  (character) Data entity identifier

- env:

  (character) Repository environment. Can be: "production", "staging",
  or "development".

## Value

(character) A 40-character SHA-1 checksum value of `entityId` in
`packageId`
